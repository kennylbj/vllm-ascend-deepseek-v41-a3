# DeepSeek-V4.1-Flash-1017 W4A8 兼容性评估

2026-11-08 静态核对。**当前项目已有加载这份 W4A8 权重所需的量化路径，可以用现有 rc2 运行时做配置级验证。** 证据覆盖模型配置、量化描述、权重索引、抽样 safetensors 文件头和固定提交的源码。当前仓库的 A3 `DP2/TP8 + MRV2 + DSpark` 组合仍需实机验收。

## 权重与加载路径

- Eco-Tech 的两套 `config.json` 字节相同，均为 `deepseek_v41` / `DeepseekV41ForCausalLM`。两套量化描述的顶层 `group_size` 都为 `0`，`model_quant_type` 都写着 `W8A8_DYNAMIC`。W4A8 版按张量声明主模型路由专家为 `W4A8_DYNAMIC`，共享专家和部分注意力投影仍为 `W8A8_DYNAMIC`。随附的 ModelSlim 配方也将路由专家配置为 per-channel INT4 权重、per-token INT8 激活。 [W4A8 模型配置](https://www.modelscope.cn/api/v1/models/Eco-Tech/DeepSeek-V4.1-Flash-1017-w4a8/repo?Revision=master&FilePath=config.json) · [W8A8 模型配置](https://www.modelscope.cn/api/v1/models/Eco-Tech/DeepSeek-V4.1-Flash-1017-w8a8/repo?Revision=master&FilePath=config.json) · [W4A8 量化描述](https://www.modelscope.cn/api/v1/models/Eco-Tech/DeepSeek-V4.1-Flash-1017-w4a8/repo?Revision=master&FilePath=quant_model_description.json) · [W8A8 量化描述](https://www.modelscope.cn/api/v1/models/Eco-Tech/DeepSeek-V4.1-Flash-1017-w8a8/repo?Revision=master&FilePath=quant_model_description.json) · [W4A8 量化配方](https://www.modelscope.cn/api/v1/models/Eco-Tech/DeepSeek-V4.1-Flash-1017-w4a8/repo?Revision=master&FilePath=DeepSeek-V4.1-Flash_best_practice.yaml)
- 抽查 W4A8 首个分片文件头，`layers.0.ffn.experts.0.w1/w3.weight` 为 `I8 [1152, 5120]`，`w2.weight` 为 `I8 [2560, 2304]`，每个 `I8` 元素打包两个 INT4 值。`w1/w3.scale_bias` 为 `F32 [2304, 1]`，`w2.scale_bias` 为 `F32 [5120, 16]`，与 rc2 的 ModelSlim W4A8 MoE 加载形状一致。启用 EP 时，量化实现使用专家内部 TP 1。 [W4A8 权重索引](https://www.modelscope.cn/api/v1/models/Eco-Tech/DeepSeek-V4.1-Flash-1017-w4a8/repo?Revision=master&FilePath=quant_model_weights.safetensors.index.json) · [固定提交的 W4A8 实现](https://github.com/vllm-project/vllm-ascend/blob/8fde6d4e3/vllm_ascend/quantization/methods/w4a8/w4a8.py#L118-L277)
- 项目通过 `--quantization ascend` 进入 ModelSlim 路径。固定的 `8fde6d4e3` 已包含 V4.1 权重名映射、按层查找量化类型、MoE `scale_bias` 加载和 `W4A8_DYNAMIC` MoE 注册。用 rc2 的 `get_quant_type_for_layer` 对两份量化描述做离线检查，W4A8 的 40 层主模型路由专家均解析为 `W4A8_DYNAMIC`，W8A8 的 40 层均解析为 `W8A8_DYNAMIC`。 [启动参数](../scripts/serve.sh#L284-L330) · [V4.1 名称映射](https://github.com/vllm-project/vllm-ascend/blob/8fde6d4e3/vllm_ascend/quantization/configs/modelslim_config.py#L171-L229) · [ModelSlim MoE 加载](https://github.com/vllm-project/vllm-ascend/blob/8fde6d4e3/vllm_ascend/quantization/configs/modelslim_config.py#L744-L757) · [W4A8 MoE 注册](https://github.com/vllm-project/vllm-ascend/blob/8fde6d4e3/vllm_ascend/quantization/methods/w4a8/w4a8.py#L118)
- 两套权重含相同格式和尺寸的 INT8 Engram。W4A8 权重索引指向 85 个分片，W8A8 指向 142 个分片。计入 `optional/quarot.safetensors`，ModelScope 的 safetensors 合计分别为约 529 GB 和 781 GB，缩减约 32%。两套权重的 Engram 分片均约 203 GB，因此不能按主权重的缩减比例推算主机内存。模型配置使用 `quarot_global` Engram value basis，部署时应保留 `optional/quarot.safetensors`。 [W4A8 文件清单](https://www.modelscope.cn/api/v1/models/Eco-Tech/DeepSeek-V4.1-Flash-1017-w4a8/repo/files?Revision=master&Recursive=true) · [W8A8 文件清单](https://www.modelscope.cn/api/v1/models/Eco-Tech/DeepSeek-V4.1-Flash-1017-w8a8/repo/files?Revision=master&Recursive=true) · [模型配置](https://www.modelscope.cn/api/v1/models/Eco-Tech/DeepSeek-V4.1-Flash-1017-w4a8/repo?Revision=master&FilePath=config.json)

## 验收范围

1. 在空闲 A3 或维护窗口，把 `DSV41_MODEL` 指向完整的 W4A8 权重目录，保留 `--quantization ascend` 和 EP，先以 `DSV41_DP=4`、`DSV41_TP=4` 复用官方拓扑。如果 Docker 容器当前只挂载了外部 W8A8 目录，需用 W4A8 配置重建容器或准备有新挂载的容器。 [模型挂载](../scripts/container.sh#L205-L218) · [重建命令](../scripts/container.sh#L369-L377)
2. `DSV41_PROBE=1` 只导入运行时并检查设备数。实际启动后验证量化加载、图捕获、`/health` 和 `/v1/chat/completions`，再覆盖 DSpark、长上下文和并发负载。若部署 Docker 示例默认启用的 Memcache，项目会拒绝 `--swa-bounded-replay`，应分别验收官方 SWA 配置和项目的 Memcache 配置。 [环境探测](../scripts/serve.sh#L271-L282) · [Memcache 默认值](../config/dsv41.docker.env.example#L76-L84) · [参数冲突检查](../scripts/serve.sh#L340-L354) · [接口验证](https://docs.vllm.ai/projects/ascend/en/latest/tutorials/models/DeepSeek-V4.1-Flash.html#56-service-verification)
3. 将原有 `DP2/TP8` 作为单独的验收项。量化配方的 QuaRot 段使用 `online: false`，其中的 `max_tp_size: 4` 只约束启用在线旋转的部署。固定提交的 W4A8 MoE 路径会调用 `grouped_matmul_swiglu_quant_v2`。上游曾报告较早的专用 A3 镜像在 W4A8 `TP8 + EP` 的长输入与并发混合负载下出现该算子的设备错误，实际 rc2 镜像与配置需要单独验证。 [W4A8 量化配方](https://www.modelscope.cn/api/v1/models/Eco-Tech/DeepSeek-V4.1-Flash-1017-w4a8/repo?Revision=master&FilePath=DeepSeek-V4.1-Flash_best_practice.yaml) · [QuaRot 参数](https://mindstudio-docs-master.readthedocs.io/zh-cn/latest/msmodelslim/docs/en/user_guide/quantization_algorithms/outlier_suppression_algorithms/quarot/#yaml-configuration-fields) · [固定提交的算子调用](https://github.com/vllm-project/vllm-ascend/blob/8fde6d4e3/vllm_ascend/quantization/methods/w4a8/w4a8.py#L599-L609) · [上游问题 #19722](https://github.com/vllm-project/vllm-ascend/issues/19722)
